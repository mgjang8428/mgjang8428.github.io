### 실행을 위해 필요한 작업

Antigravity App v2.32.1 버전 기준</br>

1. Antigravity 홈페이지에서 Linux용 설치 파일 다운로드   
https://antigravity.google/download/

2. 받은 파일을 압축해제
```
tar -zxvf ./Antigravity.tar.gz
```
3. 폴더 내부로 위치 이동
```
cd ./Antigravity/Antigravity-x64
```
4. chrome-sandbox 파일의 권한 수정
```
sudo chown root:root ./chrome-sandbox
sudo chmod 4755 ./chrome-sandbox
```
5. Antigravity 실행
```
./antigravity
```
<br/>

* 빠른 실행을 위한 바로가기, 링크는 별도의 작업이 필요합니다.
* Antigravity IDE는 같은 작업을 하되 폴더명 중간 공백을 없애야 합니다.
    * mv ./Antigravity IDE ./AntigravityIDE

### [추가] 앱 서랍 OR 바탕화면 바로가기 생성
1. Antigravity 폴더 내부에 antigravity.desktop 이름으로 파일을 생성합니다.
> $ nano antigravity.desktop

중요! [ ] 는 개인에 맞춰 수정이 필요합니다.

``` text
[Desktop Entry] # 수정X
Version=1.0
Type=Application
Name=Antigravity
Comment=Google Antigravity
Exec=[Antigravity 경로]/Antigravity/Antigravity-x64/antigravity %U
Path=[Antigravity 경로]/Antigravity/Antigravity-x64
Icon=[Antigravity 아이콘 경로]/Antigravity/Antigravity-x64/icon.png # 생성예정
Terminal=false
Categories=Development;IDE;TextEditor;
StartupNotify=true
StartupWMClass=Antigravity
```

``` bash
# 1. Antigravity 경로로 이동
cd [Antigravity 경로]

# 2. 아카이브에서 아이콘 꺼내기 (Node.js 필요), 현재 폴더에 icon.png가 생김
npx @electron/asar extract-file resources/app.asar icon.png

# 2. 바로가기를 앱 서랍에 등록
chmod +x antigravity.desktop
cp antigravity.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications 2>/dev/null

# (선택) 바탕화면에도 두려면
cp antigravity.desktop ~/Desktop/   # 우클릭 → "실행 허용" 필요!
```
